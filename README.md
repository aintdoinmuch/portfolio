## 🚀 How to Run Locally

Because the project is built with clean, zero-dependency static web standards, no compilation or `npm install` is required!

### Option 1: Direct Double-Click
Simply open `index.html` in any web browser (Chrome, Edge, Firefox, Safari).

### Option 2: Local Python Server (Recommended)
Open PowerShell or your terminal in this directory and run:

```bash
python -m http.server 8000
```

Then visit:
```
http://localhost:8000
```

## 🌐 Free 1-Click Deployment Options

### Deploy on GitHub Pages
1. Push this folder to a GitHub repository (e.g. `namangarg/namangarg.github.io`).
2. In your repo settings, go to **Pages** > **Build and deployment** > Source: **Deploy from a branch** (`main` / `/root`).
3. Your portfolio is live at `https://<your-username>.github.io`!

### Deploy on Vercel / Netlify
- Drag and drop this folder directly into [Vercel](https://vercel.com) or [Netlify Drop](https://app.netlify.com/drop). It will deploy instantly with HTTPS and a custom domain.
